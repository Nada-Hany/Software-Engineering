# 🎬 Cinema Management System

### The Cinema System is a software application designed to manage cinema operations, including movie scheduling, Moviw Shows, Movie Categories, ticket booking, customer management, and reporting. The system aims to streamline processes for cinema staff and provide a user-friendly interface for customers to browse movies, book tickets, and view showtimes. This project is developed as part of the Software Engineering course, covering Phase 1 (Requirements and Design) and Phase 2 (Implementation).

## 📌 Features

- 🎟️ **Ticket Booking**  
  Users can browse available movies and book tickets for preferred showtimes.

- 🕒 **Movie Scheduling**  
  Admins can add, update, or remove movie schedules.
  
- 🧾 **Customer Management**  
  Store and manage user information and booking history.

- 💺 **Seat Selection**  
  View available seats and choose specific seats during booking.

- 🧑‍💼 **Admin Panel**  
  Secure admin login to manage the cinema system (movies, seats, timings, etc.).

- 📊 **Reports**  
  Generate daily/weekly reports for booked tickets, revenue, and customer visits.

## 🧠 Technologies Used

- **C# .NET (Windows Forms)**
- **Oracle SQL (Back-end Database)**
- **ODP.NET** (Oracle Data Provider for .NET)
- **Crystal Reports**
- **Microsoft Visual Studio**
